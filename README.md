Анализ успеваемости на JavaScript. Индивидуальная работа:
Дубограй Дмитрий Юрьевич, ОКБИ-301б.

## Запуск

Нужен Node.js 18 или новее. Сторонние библиотеки не используются;
`npm install` не требуется.

```powershell
node main.js
node --test
```

Также доступны `npm start` и `npm test`.

## Структура

- `main.js` — массив оценок, подключение модулей и вывод всех результатов.
- `calculateAverage.js` — средний балл группы.
- `findTopStudent.js` — имя студента с максимальным баллом.
- `filterFailed.js` — имена студентов с баллом ниже проходного.
- `addLetterGrade.js` — новый массив с полем `letter`.
- `test/grades.test.js` — 6 проверок результатов и граничных случаев.
- `results.txt` — вывод проверочного запуска.
- `GIT_GUIDE.md` — просмотр истории и дальнейшая работа с Git.

## Результаты

Средний балл — **77.6**; лучший студент — **Денис** (92);
должник при проходном балле 60 — **Студент_X** (45).
Буквенные оценки: Макар — B, Денис — A, Анна — B, Даша — B,
Студент_X — C.

A: score >= 90; B: 75 <= score < 90; C: score < 75.
Должник определяется отдельно по score < 60. Например, 60 баллов —
это C, но проходной балл уже набран.

## Граничные случаи

Для пустой группы `calculateAverage()` и `findTopStudent()` возвращают
`null`, остальные функции — `[]`. При равном максимуме выбирается
первый студент. `addLetterGrade()` создаёт копии объектов и сохраняет
исходные данные. Входные записи имеют поля `name` и числовой `score`
от 0 до 100, как в задании.

## Git и Pull Request

Ветки: `main`, `develop`, `feature/dubograi`. Каждая функция сохранена
отдельным коммитом. Интеграция проходит через Pull Request из
`feature/dubograi` в `develop`, затем из `develop` в `main`.
Работа выполнена одним автором с самопроверкой; независимое командное
ревью не имитируется. Имена в массиве взяты из условия задания.
